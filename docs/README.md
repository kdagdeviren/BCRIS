# BCRIS Proje Dokümantasyonu

Bu klasör, BCRIS projesinin geliştirme sürecinde oluşturulan tüm dokümantasyon dosyalarını içerir.

## 📚 Dokümantasyon Kategorileri

### Ana Dokümantasyon
- **README.md** - Proje ana dokümantasyonu
- **README_DJANGO.md** - Django implementasyonu hakkında
- **DATABASE_DRIVEN_SYSTEM.md** - Veritabanı tabanlı sistem açıklaması

### Özellik Dokümantasyonları

#### Hekim Sistemi
- **HEKIM_SISTEMI_README.md** - Hekim kayıt ve giriş sistemi
- **HEKIM_VE_VERI_SISTEMI.md** - Hekim veri yükleme sistemi

#### Çoklu Dil Desteği
- **COKLU_DIL_VE_ADMIN_LINK.md** - Çoklu dil ve admin linkleri
- **CEVIRME_OZETI.md** - Çeviri sistemi özeti
- **UNIFIED_LANGUAGE_SYSTEM.md** - Birleşik dil sistemi
- **AUTH_BUTTONS_TRANSLATION.md** - Auth butonları çevirisi
- **SIGNUP_FORM_TRANSLATION_FIX.md** - Signup form çeviri düzeltmesi

#### Admin Panel
- **ADMIN_PANEL_KULLANIMI.md** - Admin panel kullanım kılavuzu
- **ADMIN_PANEL_BEAUTIFICATION.md** - Admin panel güzelleştirme
- **ADMIN_DOSYA_INDIRME.md** - Admin dosya indirme özelliği
- **ADMIN_LINK_ANASAYFA.md** - Admin panel ana sayfa linkleri

#### Ana Sayfa
- **ANA_SAYFA_GUNCELLENDI.md** - Ana sayfa güncellemeleri
- **THESIS_MODAL_USER_BASED.md** - Tez modalı kullanıcı bazlı gösterim
- **VARIABLE_INFO_FIX.md** - Değişken bilgi düzeltmesi

#### Yeni Özellikler
- **DOWNLOADABLE_FILES_ADMIN.md** - İndirilebilir dosyalar yönetimi
- **FEATURE_PREDICTION_CONTROL.md** - Özellik tahmin kontrolü
- **YENI_OZELLIKLER_KULLANIM.md** - Yeni özellikler kullanım kılavuzu
- **YENI_OZELLIKLER_PLANI.md** - Yeni özellikler planı

### Durum Raporları
- **SISTEM_DURUMU_RAPORU.md** - Sistem durum raporu
- **TAMAMLANAN_OZELLIKLER_OZET.md** - Tamamlanan özellikler özeti
